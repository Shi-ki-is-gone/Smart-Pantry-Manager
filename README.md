# Smart Pantry Manager (Java, SQLite)

## Open in Android Studio

Open this project root folder (the one containing `settings.gradle`) in Android Studio, then allow Gradle sync to finish. The project uses Gradle 8.7, Android Gradle Plugin 8.5.2, and Android SDK Platform 34. If Android or AndroidX imports are unresolved, run **File > Sync Project with Gradle Files** and check the Build output for sync errors.
